# Avera Portal

Create an ultra-luxurious, responsive full-stack website for "AVERA" — an elite event management & luxury wedding planning umbrella combining high-end weddings and corporate event production.
Brand Identity & Aesthetic:
Minimalist editorial luxury (haute-couture magazine aesthetic, warm neutral elegance).
Color Palette: Deep obsidian black, ivory pearl white, warm muted sand/beige, and subtle champagne gold accents.
Typography: High-contrast editorial Serif (Playfair Display / Cormorant Garamond) for headers; clean modern Sans-serif (Inter) for body text.
Brand Slogan: "AVERA — Before Forever" & "Avera isn't just a name... It's a promise".
